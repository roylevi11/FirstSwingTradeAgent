## מה זה
סוכן שסורק מניה, שולף נתוני שוק ומועד דוחות אמיתיים, מריץ חישוב יחס סיכון/סיכוי
מדויק בקוד (לא בניחוש), אוכף חוקי ברזל דטרמיניסטיים, ומפיק תזכיר עסקה (Trade
Setup Memo) שממתין לאישור אנושי — Approval-Based Copilot, בדיוק לפי העיקרון
שהוגדר בעבודה 1.

**ההבדל המהותי מהגרסה ב-AI Studio:** שם החוקים היו טקסט בהוראות המערכת שה-LLM
התבקש "לזכור ולציית". כאן הם קוד פייתון אמיתי (`tools/rules_engine.py`) שרץ
*לפני* שכל תזכיר יוצא — ה-LLM לא יכול לעקוף אותו, גם לא בטעות.

## מבנה הפרויקט
```
swing_copilot/

├── tools/

│   ├── similarity.py         # Phase C: Cosine/Jaccard בקוד אמיתי, סקיילבילי
│   ├── patterns.py           # Phase B: זיהוי תבניות (DREAM-02) - Inside Bar/Breakout/...
│   ├── indicators.py         # Phase B: RSI/ATR/SMA/EMA/נפח יחסי (DREAM-03)
│   ├── market_data.py        # yfinance: מחיר, שווי שוק, OHLC (כולל תוך-יומי, DREAM-01 חלקי)
│   ├── earnings.py           # yfinance: מועד דוחות קרוב
│   └── orders.py             # תזכיר עסקה + Audit Log (רואה ל-REQ-04)
├── agent/
│   ├── prompts.py            # System Prompt — גרסה מתורגמת מ-AI Studio
│   ├── tool_definitions.py   # סכמות ה-Tool Use עבור Claude API
│   └── loop.py               # לולאת Observe-Think-Act בפועל
├── tests/
│   └── test_rules_engine.py  # משחזר את 3 מקרי הבדיקה מעבודה 1/2 — 9/9 עוברים
│   └── test_similarity.py    # משחזר את ממצאי עבודה 3 (Cosine/Jaccard) — 7/7 עוברים
│   ├── test_patterns.py      # תבניות טכניות עם נתונים סינתטיים — 12/12 עוברים
│   └── test_indicators.py    # RSI/ATR/SMA/EMA/נפח — 7/7 עוברים
├── eval/                      # דרישות הקורס: נושא 3 (ולידציה + מבחן עמידות)
│   ├── validation_questions.json   # 8 שאלות עם תשובה ידועה
│   ├── stress_test_questions.json  # 5 שאלות "קשות"
│   └── run_evaluation.py           # מריץ הכל מול הסוכן, מפיק evaluation_report.md
├── data/
│   └── watchlist.csv         # רשימת מעקב מאוחדת = שכבת ה-Knowledge (12 מניות)
```

## דרישות הקורס — איפה למצוא כל דבר
| דרישת הקורס | איפה כאן |
|---|---|
| טבלת 5 רכיבי הארכיטקטורה | ראו קובץ שלב 5 (מחוץ ל-zip הזה) |
| כלי חדש + הדגמת אוטונומיה | `agent/tool_definitions.py` (web_search) + `tools/watchlist.py` (Knowledge חדש) |
| פיילוט רב-סוכני (בונוס) | `agent/client_message_agent.py` — סוכן ב' הופך תזכיר להודעת לקוח |
| סט ולידציה + מבחן עמידות | `eval/` — `python -m eval.run_evaluation` (דורש רשת + API key) |
| רשימת בטיחות/אתיקה | `agent/prompts.py`, סעיף "בטיחות ואתיקה" |

## מיפוי מול מפת הדרכים (13 החלומות)
Phase A ממש חלק מהתשתית שכל שאר החלומות ייבנו עליה, ובנוסף מימוש **חלקי** של:
- **DREAM-01** (נתונים חיים) — yfinance מחליף CSV סטטי; עדיין לא Tick-by-Tick בזמן אמת.
- תשתית ל-**REQ-04 / Audit Log** — כל תזכיר (מאושר/נדחה) נשמר אוטומטית ל-`data/audit_log.csv`.

עדיין לא ממומש (מתוכנן לפאזות הבאות): DREAM-01 המלא (Tick-by-Tick בתשלום),
DREAM-08/09/10 (RAG ומקורות חיצוניים, Phase E), DREAM-05/06/07
(דשבורד, בונה תבניות, טלגרם, Phase F).

## עקרונות תכנון שנשמרו מהעבודות הקודמות
1. **איסור המצאות** — כל כלי נתונים מחזיר `None` / מדווח על שדה חסר, לעולם לא ממציא ערך (לקח מהניסוי מול TradingView).
2. **הפרדת לוגיקה מחישוב** — שום חישוב מספרי לא "בראש" של המודל; הכל דרך `evaluate_trade`.
3. **Approval-Based Copilot** — הסוכן לעולם לא "מבצע" עסקה; רק מכין טיוטה וממתין.
4. **שערים דטרמיניסטיים** — תוצאת `rules_engine` היא סופית; אין למודל סמכות "לשכנע את עצמו".
