## מה זה
סוכן שסורק מניה, שולף נתוני שוק ומועד דוחות אמיתיים, מריץ חישוב יחס סיכון/סיכוי
מדויק בקוד (לא בניחוש), אוכף חוקי ברזל דטרמיניסטיים, ומפיק תזכיר עסקה (Trade
Setup Memo) שממתין לאישור אנושי — Approval-Based Copilot, בדיוק לפי העיקרון
שהוגדר בעבודה 1.

**ההבדל המהותי מהגרסה ב-AI Studio:** שם החוקים היו טקסט בהוראות המערכת שה-LLM
התבקש "לזכור ולציית". כאן הם קוד פייתון אמיתי (`tools/rules_engine.py`) שרץ
*לפני* שכל תזכיר יוצא — ה-LLM לא יכול לעקוף אותו, גם לא בטעות.

## שכבת הדמיון החיה
`find_similar_stocks` (`tools/live_similarity.py`) פועל על נתונים חיים בלבד (7 טווחי זמן, 5m עד 1W):
| קבוצת מאפיינים | משקל | תוכן |
|---|---|---|
| קורלציית התנהגות | 0.20 | קורלציית תשואות יומיות היסטורית (6 חודשים) |
| תבנית | 0.20 | תבנית ראשית + כל צמדי (תבנית, טווח זמן); **"אין תבנית" (None) הוא ערך לגיטימי** |
| מצב טכני | 0.25 | מומנטום 5/20/60 יום, מרחק מ-SMA20/50/200, RSI, MACD, מיקום בערוץ, R:R חי, יישור מגמה בין טווחים |
| פרופיל סיכון | 0.10 | ATR%, בטא |
| סקטור/תעשייה | 0.10 | |
| דוחות | 0.05 | ימי מסחר עד הדוחות |
| יסודות | 0.10 | שווי שוק, מכפיל רווח |

קבוצה שחסר בה נתון נושרת והמשקלים מנורמלים מחדש (לא ממציאים ערך). **תיעדוף לפי סטטיסטיקה:** `python -m tools.pattern_stats` מריץ בדיקת עבר על ~1,130 מניות S&P 500 + נאסד"ק
(שווי מעל $2B; 2 שנים, אופק 10 ימים, סטופ = שפל 20 יום, יעד 2R) ושומר `data/backtest_report.json` (דוח מלא)
ו-`data/pattern_stats.json` (מה שהדמיון קורא). הדירוג הסופי: `0.7 * דמיון + 0.3 * Edge היסטורי`,
כשה-Edge נמדד זוגית פר-מניה מול ימים בלי תבנית (`config/similarity_config.py`, `EDGE_SCALE_R`).

תוצאות (תוחלת ב-R; קו בסיס "ללא תבנית" = +0.069R, n=336,651):
| תבנית | n | תוחלת | Excess זוגי | t | חצי ראשון / שני (תוחלת) | Edge |
|---|---|---|---|---|---|---|
| Inside Bar | 59,162 | +0.086 | +0.024 | +5.3 | +0.103 / +0.072 | 0.58 |
| Breakout Confirmation | 8,867 | +0.054 | -0.046 | -5.9 | +0.043 / +0.063 | 0.35 |
| Range Bound | 38,216 | -0.031 | -0.087 | -5.0 | -0.012 / -0.052 | 0.21 |
| Pullback to Support | 46,226 | -0.052 | -0.124 | -13.4 | -0.085 / -0.026 | 0.09 |

**מסקנות:** (1) מדגם רשימת המעקב בלבד הטעה - הראה את Range Bound כתבנית הטובה ביותר ו-Pullback כחיובית; ברוחב
שוק שניהם שליליים עקבית בשני חצאי התקופה. (2) Inside Bar מובהקת סטטיסטית אך זעירה כלכלית (+0.02R).
(3) Pullback to Support בהגדרה הנוכחית (סגירה עד 1.5% משפל 20 יום) היא בפועל "סכין נופלת" - אחוז הצלחה 32%.
(4) ביעד 2R ואופק 10 ימים, Breakout כמעט אינו מגיע ליעד (1.8%) כי הסטופ רחוק. **מגבלות:** Survivorship
(רשימות מדדים נוכחיות), מקרים חופפים, ללא עמלות/החלקה, יומי בלבד - אינדיקציה ולא הבטחה.

## מיפוי מול מפת הדרכים (13 החלומות)
Phase A ממש חלק מהתשתית שכל שאר החלומות ייבנו עליה, ובנוסף מימוש **חלקי** של:
- **DREAM-01** (נתונים חיים) — yfinance מחליף CSV סטטי; ניתוח רב-טווחי (5m עד 1D) פעיל; עדיין לא Tick-by-Tick אמיתי בתשלום.
- **תמיכה/התנגדות/תבנית טכנית חיות** — `analyze_multi_timeframe` הוא כעת מקור האמת לכל עסקה, לא תיוג ידני ב-CSV (ראו `tools/multi_timeframe.py`).
- **DREAM-12** (סריקת Finviz) — `tools/finviz_screener.py`, עוטף את הספרייה `finvizfinance`. **לא נבדק עם רשת אמיתית עדיין** - רק לוגיקת ההמרה שלנו.
- **DREAM-13** (סנטימנט StockTwits) — `tools/stocktwits_sentiment.py`, API ציבורי רשמי ללא מפתח. **לא נבדק עם רשת אמיתית עדיין**.
- **"BamSEC"** — הוחלף בפועל ב-**SEC EDGAR הרשמי והחינמי** (`tools/sec_filings.py`) — BamSEC הוא מוצר בתשלום עם התחברות, אין לנו גישה. יש להחליף את `SEC_USER_AGENT` בקובץ לפרטים אמיתיים לפני הרצה (SEC חוסם בלי זה).
- **DREAM-09** (Market Momentum Radar) — **הוחלט לא לבנות אינטגרציה אוטומטית**: האתר מרונדר ב-JS (כמו TradingView), ו-robots.txt חוסם גישה אוטומטית במפורש. מחכה לטקסט Methodology/How It Works שהמשתמש ימצא ידנית, כדי לבנות ציון מורכב בהשראת העקרונות (לא חיקוי ישיר).
- **DREAM-11** (P/E ושווי שוק) — הנתונים נשלפים בפועל (`fetch_market_data`), אך לפי החלטה מפורשת עדיין **לא אוכפים** כחוק ברזל - מידע בלבד כרגע.
- תשתית ל-**REQ-04 / Audit Log** — כל תזכיר (מאושר/נדחה) נשמר אוטומטית ל-`data/audit_log.csv`.

עדיין לא ממומש (מתוכנן לפאזות הבאות): DREAM-01 המלא (Tick-by-Tick בתשלום),
DREAM-08/09/10 (RAG ומקורות חיצוניים, Phase E), DREAM-05/06/07
(דשבורד, בונה תבניות, טלגרם, Phase F).

## עקרונות תכנון שנשמרו מהעבודות הקודמות
1. **איסור המצאות** — כל כלי נתונים מחזיר `None` / מדווח על שדה חסר, לעולם לא ממציא ערך (לקח מהניסוי מול TradingView).
2. **הפרדת לוגיקה מחישוב** — שום חישוב מספרי לא "בראש" של המודל; הכל דרך `evaluate_trade`.
3. **Approval-Based Copilot** — הסוכן לעולם לא "מבצע" עסקה; רק מכין טיוטה וממתין.
4. **שערים דטרמיניסטיים** — תוצאת `rules_engine` היא סופית; אין למודל סמכות "לשכנע את עצמו".
